Creator tier & audience scale

Question — Do bigger creators justify bigger fees? Compare the interaction rate (quality of attention) with interactions per 1,000 fans (efficiency of the fan base).
业务问题 — 头部达人是否配得上更高的报价？需同时看“互动率”与“每千粉丝产出”。

Median interaction rate by creator tier

Surprisingly flat across tiers — scale does not buy a higher rate. 各层级中位数互动率差异很小，规模并不直接带来更高互动率。

Interactions per 1,000 fans

The real differentiator: small accounts activate their audience far harder. 真正的差异点：小体量达人对粉丝的激活能力远强于头部。

Audience-scale view — a continuous cut on follower bands

The tier column in this dataset is heavily skewed (see the flag below), so fan-base size is re-cut into continuous bands as a cross-check. 由于层级字段分布失衡，这里用粉丝量分箱做交叉验证。

Budget allocation

Question — Given a fixed envelope, how should spend be split across creator tiers and platforms?

Modelled unit economics

Allocation scenarios — creator tier

Three ways to split the same envelope: Status quo / Even split / Efficiency-weighted. Right-hand number = expected interactions; below it, change vs. an even split. 同一预算下的三种分配方式：现状结构 / 平均分配 / 效率加权；右侧为预期互动量，其下为相对平均分配的增减。

Allocation scenarios — platform

Three ways to split the same envelope: Status quo / Even split / Efficiency-weighted. Right-hand number = expected interactions; below it, change vs. an even split. 同一预算下的三种分配方式：现状结构 / 平均分配 / 效率加权；右侧为预期互动量，其下为相对平均分配的增减。

Sensitivity to the CPM assumption

The dataset has no spend column, so cost is modelled from one declared CPM. Re-running the whole allocation at CPM 5 / 10 / 15 / 25 tests whether the recommendation survives the assumption. 数据集不含花费字段，成本由单一 CPM 假设推导；此处检验结论对该假设是否稳健。
